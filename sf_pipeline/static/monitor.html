Как работает пайплайн

Шаг 1 — Knowledge Gather
Gemini 3.6 Flash (с Google Search grounding) вызывается параллельно для каждой из 16 областей. По каждой области модель перечисляет все конкретные named события, решения, кейсы о компании.
Формат CARQ: каждая история выводится в виде блока с полями C (контекст: год, место, люди), A (подробная история), R (итог и цифры), Q (3 поисковых запроса на английском для обогащения).
Три прохода: после основного списка модель делает второй проход по каждому топику и третий финальный проход — для извлечения менее очевидных историй (знаменитые письма, инциденты, внутренние практики).
Google Search grounding: модель автономно решает, что именно нужно проверить в интернете — все запросы видны в логе. Лимит: 5000 запросов/месяц бесплатно.
Топики по областям: каждая область имеет специализированный список тем, включая Famous Stories, Named Concepts, Retail/Marketing Hacks — для вытягивания нишевых историй.
Шаг 2 — Refine
GPT-5.6 Terra получает объединённый вывод всех областей и удаляет точные дубликаты (один и тот же конкретный эпизод от разных областей). Принцип: минимум 80% от числа уникальных записей остаётся. Результат — пронумерованный список событий с краткими RU-аннотациями.
После refine пайплайн делает паузу — можно выбрать конкретные события для поиска через Brave.
Шаг 3 — Story Search + Анализ
Story queries — по выбранным событиям генерируются точные поисковые запросы. Например: "Southwest Airlines Herb Kelleher Crabapple letter customer".
Brave Search + Jina — каждый запрос → 5 URL → скрейп через Jina Reader (до 20k символов на страницу). Домен компании не исключается.
Analysis — весь контент делится на чанки ~55k символов, каждый анализируется LLM: извлекаются STAR-истории (ID, P, S, T, A, R).
Translation + Save — истории переводятся на русский, сохраняются в SQLite и .md файл.
Модели: Knowledge — Gemini 3.6 Flash (с grounding). Refine — GPT-5.6 Terra. Анализ — выбранная модель (по умолчанию GPT-5.6 Luna). Story queries — выбранная модель.
Стоимость: ~$0.05–0.10 за компанию (только Gemini Flash + grounding). Brave Search: $0.003/запрос.
